Scenario 02: Database Timeout Under Load
Overview

A backend service is experiencing slow responses and intermittent failures when accessing data from the database. The issue appears after deployment and becomes worse under moderate traffic.

Symptoms
API responses are extremely slow (5–15 seconds)
Some requests fail with timeout errors
No clear crash in application logs
System appears stable but performance is degraded
Your Task

Analyze the logs and system behavior to determine:

Why requests are slowing down
What is causing intermittent timeouts
How to restore normal performance
