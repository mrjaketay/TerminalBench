Scenario 03: Environment Configuration Failure
Overview

A backend API service works correctly in development but fails after deployment to a production-like environment. The application starts, but certain features do not behave as expected.

Symptoms
API starts successfully
Authentication requests fail
External API calls do not work
No obvious crash in application logs
Same code works locally
Your Task

Investigate the logs and configuration to determine:

Why the system behaves differently in production
What configuration is missing or incorrect
How to fix the issue
